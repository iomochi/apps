# 語録採集

誰かの言葉（発言）を集めて、自分の思考や違和感とつなげて残すためのメモアプリです。
1つの `index.html` だけで動く、外部通信なしの静的ページです。

## 特徴
- 発言カードと思考カードを、双方向に紐づけられる
- 人物・所属の管理、発言者別の一覧
- カテゴリ・出典の名前変更と削除
- JSON の書き出し／読み込みでバックアップ
- データは、使う人のブラウザ（LocalStorage）にだけ保存

## 公開（GitHub Pages）
1. このリポジトリの Settings → Pages を開く
2. Source で、公開するブランチ（例：main）とフォルダ（/root）を選んで保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

公開後に URL を変えると、各自の保存データが別扱いになります。URL は変えないでください。

## 注意
- データは端末・ブラウザごとに別です。定期的に「書き出し」でバックアップしてください。
- 保存キー（LocalStorage）は `thoughtcards.v2` です。変更すると既存データを読めなくなります。
